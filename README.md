# Crack Story Archive

[Crack](https://crack.wrtn.ai) 롤플레이 스토리 제작자 아카이브.
각 작품의 **세계관 로어 사이트**와 스토리가 출력하는 **이미지**를
GitHub Pages로 호스팅합니다.

> 🌐 **https://Todokihowardo.github.io/**

## 왜 여기 있나

Crack 스토리는 상세 설명이 1000자로 제한되고, 플랫폼 내장 미디어 UI가
롤플레이 흐름을 끊습니다. 그래서

- **세계관 설명**은 이 사이트의 로어 페이지로 빼고, 스토리 상세 설명에는
  배너 링크만 둡니다.
- **이미지**는 스토리 프롬프트가 `![](…)` 형태의 직접 링크로 출력합니다.
  롤플레이 중 매 응답마다 URL이 나가므로, 경로를 정수로 인코딩해
  출력 토큰을 아낍니다.

## 작품

| 시리즈 | 작품 | 로어 사이트 | 상태 |
|---|---|---|---|
| **APEX 그랑프리**<br>규정으로 평준화된 하늘의 전투기 레이싱 | **아시아**<br>*Asia Off The Record* — 동북아 7전, 5개 팀 | [/apex/](https://Todokihowardo.github.io/apex/) | 이미지 1,440장 배치 완료 |

APEX 그랑프리는 규정(AERO)만 공유하고 **무대와 등장인물은 지역 시리즈마다
다릅니다.** 그래서 시리즈별로 로어 페이지를 따로 두되, 이미지 축은 겹치는
만큼 재사용합니다.

## 구조

```
/                     이 페이지(작품 목록)
/apex/                APEX 그랑프리 · 아시아 시리즈
  index.html          로어 사이트
  title.webp          타이틀 로고
  css/  js/
  c/{인}/{의}/{감}.webp   인물 — 캐릭터 · 의상 · 상황
  p/{장}.webp             장소
  j/{기}.webp             기체
```

- 경로는 전부 **정수**입니다. 정수 ↔ 이름 대응표는 각 스토리의 프롬프트가
  들고 있어, 롤플레이 AI는 짧은 URL만 출력하면 됩니다.
- `assets/` 같은 중간 폴더를 두지 않습니다. 매 출력마다 나가는 URL이라
  한 글자도 낭비하지 않습니다.
- **런타임 축은 실제 파일의 부분집합입니다.** 프롬프트가 이름 붙인 인덱스만
  출력되고(`지정 정수 외 생성 금지`), 그 뒤 번호는 로어 사이트 전용으로
  남습니다. 한 번 렌더해서 두 용도를 모두 채웁니다.
- 모든 이미지는 **WebP**이며 메타데이터(EXIF·ICC)를 제거해 올립니다.
- 새 작품은 최상위에 폴더를 하나 추가하는 방식으로 확장합니다.
- **같은 시리즈의 다른 지역**을 추가할 때는 로어 페이지만 하위 폴더로
  가르고(`/apex/eu/`), 이미지 축(`c/ p/ j/`)은 상위에서 공유합니다 —
  이미 등록된 스토리의 이미지 URL이 바뀌지 않아야 합니다.

## 여기 올리지 않는 것

**성인 이미지는 이 저장소에 두지 않습니다.** GitHub 이용약관이 성적으로
노골적인 콘텐츠를 제한하고, GitHub Pages는 무료 플랜에서 공개 저장소만
지원하므로 URL을 아는 누구나 접근할 수 있습니다. 여기에는 표정·일상·가벼운
스킨십까지만 올립니다.

## 이용 안내

이미지와 로어 텍스트는 해당 스토리를 위해 제작된 것입니다.
무단 재배포·상업적 이용은 삼가 주세요. 오류나 문의는 Issues로.
